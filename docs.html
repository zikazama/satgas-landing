SATGAS Documentation

SATGAS menyatukan LangGraph, agent registry, dan tooling untuk menghasilkan aplikasi full-stack berdasarkan prompt satu paragraf. Langkah demi langkah menghasilkan spec, code, security analysis, QA finding, hingga deploy-ready artifacts.

Recommended start
Ikuti Quickstart lalu pelajari Agent Pipeline dan Workflow Modes.

Core Concepts

Agents

Delapan agent kolaboratif (Orchestrator, Product Spec, Backend, Frontend, Testing, Security, QA, DevOps) dengan output terstruktur. Agent dapat berjalan paralel untuk efisiensi.

LLM Providers

Dukungan Qwen CLI lokal dan OpenAI API (termasuk Azure, Together AI, endpoint custom). Dikonfigurasi lewat LLM_PROVIDER di .env.

Outputs

Semua hasil disimpan incremental di projects/, lengkap prompt, specs, docs, threat model, code, docker, dan CI/CD.

Workflow

LangGraph menjalankan nodes agent sesuai registry dengan mode paralel atau sequential. State dikelola dengan TypedDict dan merge reducers.

Quickstart

  1. Clone repo dan pasang dependency.
  2. Salin .env.example ke .env lalu pilih LLM_PROVIDER (qwen atau openai).
  3. Jalankan python run.py, buka Streamlit UI di http://localhost:8501.
  4. Tulis prompt + stack, lalu biarkan agent pipeline bekerja.
  5. Hasil aplikasi tersimpan di folder projects/YYYYMMDD_HHMMSS_nama-project/.
Dev setup 
git clone https://github.com/zikazama/SATGAS
cd SATGAS
pip install -r requirements.txt
cp .env.example .env
python run.py
Konfigurasi .env 
# Pilih provider: qwen atau openai
LLM_PROVIDER=qwen

# Qwen CLI (lokal)
QWEN_CLI_COMMAND=qwen
QWEN_TIMEOUT=0

# OpenAI API
OPENAI_API_KEY=sk-your-key
OPENAI_MODEL=gpt-4o-mini
OPENAI_TEMPERATURE=0.7
OPENAI_MAX_TOKENS=4096

Workflow Modes

Default parallel mode menjalankan agent independent secara bersamaan. Sequential mode membantu debugging.

Parallel Mode (Default)

Backend & Frontend berjalan paralel. Testing, Security, QA juga paralel.

Orchestrator
    ↓
Product Spec
    ↓
┌───┴───┐
Backend  Frontend  ← paralel
└───┬───┘
    ↓
┌───┼───┐
Test Security QA  ← paralel
└───┬───┘
    ↓
  DevOps

Sequential Mode

Semua agent berjalan satu per satu, berguna untuk debugging.

Orchestrator
    ↓
Product Spec
    ↓
Backend
    ↓
Frontend
    ↓
Testing
    ↓
Security
    ↓
QA → DevOps

Security & Guardrails

Policy engine mengatur tool allowlist, network egress, approval gates, dan audit log.

Policy example 
name: safe-default
tools:
  allowlist:
    - http.request
    - git.clone
    - db.query
network:
  egress:
    allow:
      - "api.github.com"
gates:
  approval:
    required_for:
      - "db.migrate"
      - "prod.deploy"
data:
  pii_redaction: true
audit:
  enabled: true
  • RBAC per project/environment
  • Secrets injection (hindari logging secrets)
  • Audit logs append-only

Membuat Agent Baru

  1. Buat file agent di src/agents/ yang extends BaseAgent.
  2. Definisikan metadata: agent_id, agent_name, step_order, output_fields, required_fields.
  3. Override build_prompt() untuk membuat prompt LLM.
  4. Override process_response() untuk memproses respon LLM.
  5. Tambahkan ke AGENT_CLASSES di src/agents/registry.py.
  6. Update AppGenerationState di src/core/state.py jika perlu.
Contoh Agent 
from .base import BaseAgent
from typing import Dict, Any

class MyAgent(BaseAgent):
    agent_id = "my_agent"
    agent_name = "My Agent"
    display_name = "My Agent"
    step_order = 9
    description = "Deskripsi agent"
    color = "#FF5722"

    output_fields = [
        ("my_output", "my_output.json", "json"),
    ]
    required_fields = ["spec"]

    def build_prompt(self, state: Dict[str, Any]) -> str:
        spec = state.get("spec", "")
        return f"""Kamu adalah {self.display_name}.

TUGAS: [deskripsi tugas]

INPUT:
{spec}

{self.get_file_format_instructions()}
"""

    def process_response(self, state: Dict[str, Any], response: Any) -> Dict[str, Any]:
        state["my_output"] = response.content
        state["status"] = "my_agent_done"
        return state

BaseAgent Methods

  • build_prompt(state) - Membuat prompt untuk LLM
  • process_response(state, response) - Memproses respon LLM
  • execute(state) - Main execution (biasanya tidak di-override)
  • get_file_format_instructions() - Mendapatkan instruksi format file
  • skip_execution(state, reason) - Skip agent dengan alasan
